# param-K1s

Новый проект Excel для поиска параметров по источнику `1ST/2ST`, размеру `Size` и части заголовка.

**[Скачать готовый проект Excel — ZIP, около 30 МиБ](https://github.com/Igor-Afanasev/param-K1s/raw/refs/heads/main/downloads/Parameters_by_Size_Project.zip)**

В архиве: книга `Parameters_by_Size_New.xlsx`, 170 встроенных карточек, VBA-модуль и инструкция по установке.

Поиск, средние значения, количество чисел и ссылки на полные карточки работают в `.xlsx`. Для автоматического превью в столбце G сохраните книгу как `.xlsm` и подключите код по [инструкции](docs/НАЧНИТЕ_ЗДЕСЬ.txt).

Расчёты проверены принудительным пересчётом в LibreOffice: контроль `175/65R14 + R1013` даёт `351,5` для 1ST и `5,25` для 2ST, по четыре значения. VBA проверен статически; компиляция и запуск в Microsoft Excel здесь не выполнялись. Подробнее: [проверки](docs/ПРОВЕРКИ.txt).
