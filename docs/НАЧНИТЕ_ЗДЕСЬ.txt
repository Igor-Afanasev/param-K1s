НОВЫЙ ПРОЕКТ: ПОИСК ПАРАМЕТРОВ ПО SIZE

Файл Parameters_by_Size_New.xlsx содержит оба источника данных и 170 полных карточек.
Изображения встроены в книгу. Папка со схемами для работы не нужна.

ЧТО УЖЕ РАБОТАЕТ В XLSX
1. Откройте лист «Поиск параметров».
2. D4 — источник 1ST / 2ST; D5 — размер Size; D6 — часть заголовка параметра.
3. Пустой D6 показывает все заголовки выбранного источника.
4. Среднее, число числовых значений, пояснение и область применения меняются формулами.
5. Ссылка в K открывает полную карточку на одном из листов «Карточки 1ST/2ST».

ПРИМЕР ДЛЯ ПРОВЕРКИ
D4=1ST; D5=175/65R14; D6=R1013 → IW, среднее 351,500, количество 4.
D4=2ST; D5=175/65R14; D6=R1013 → HT, среднее 5,250, количество 4.
Это разные параметры: карточки 1ST и 2ST также разные.

КАК ВКЛЮЧИТЬ ПРЕВЬЮ В СТОЛБЦЕ G (ОДИН РАЗ, В НАСТОЛЬНОМ EXCEL)
1. Сначала сохраните новую книгу через «Файл → Сохранить как».
   Тип: «Книга Excel с поддержкой макросов (*.xlsm)».
   Не меняйте расширение простым переименованием.
2. Alt+F11 откроет редактор VBA. Ctrl+R покажет проекты.
   Выберите проект именно новой книги .xlsm.
3. «File → Import File / Файл → Импорт файла»: импортируйте ParameterCards.bas.
   Появится обычный модуль ParameterCards с полным кодом.
   Если этот модуль уже есть, повторно его не импортируйте.
4. В разделе Microsoft Excel Objects дважды щёлкните ThisWorkbook («ЭтаКнига»).
   Откройте ThisWorkbook_code.txt в Блокноте, скопируйте весь текст и вставьте
   в окно кода ThisWorkbook новой книги. Это именно объект книги, а не обычный модуль.
5. В редакторе выберите «Debug → Compile VBAProject» («Отладка → Компиляция»).
   Этот шаг проверяет компиляцию в вашей версии Excel.
6. Вернитесь в Excel. Alt+F8 → InstallParameterCards → «Выполнить».
   Появятся превью и кнопка «Обновить схемы». Кнопке макрос назначается кодом.
7. Сохраните .xlsm. При следующем открытии разрешите выполнение макросов этой книги.
   После установки меняйте D4–D6: превью должно соответствовать результатам.
   Для принудительного обновления используйте кнопку.

После установки все данные, картинки и код находятся внутри одного .xlsm.
Отдельные .bas/.txt для повседневной работы больше не нужны.

ДАННЫЕ И ОБНОВЛЕНИЕ
Рабочие листы «Данные 1st/2st» содержат приведённые числовые значения.
Их числовые правки пересчитываются автоматически. Ноль считается числом;
пустые и текстовые значения не входят в среднее. Новую текстовую выгрузку
нельзя просто считать готовыми числами: она требует повторного приведения.
Диапазон наблюдений: строки 2–10001. Size должен быть без пробелов по краям.
Новые столбцы, заголовки и полное обновление выгрузки требуют пересборки структуры.
Скрытые листы «_Оригинал 1ST/2ST» сохраняют точные исходные текстовые значения.

ГРАНИЦЫ ПРОВЕРКИ
Расчёты и изменение входных данных проверены принудительным пересчётом в LibreOffice.
VBA проверен статически: процедуры и необходимые имена присутствуют.
Компиляцию и работу Copy/Paste изображений в Microsoft Excel здесь выполнить нельзя;
они проверяются шагами 5–7 выше. Готовый файл .xlsm здесь не создавался.
